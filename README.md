# VG Nail Studio Landing

Primera demo mobile-first para presentar VG Nail Studio: landing premium con Next.js App Router, Tailwind CSS, JavaScript/JSX, galería interactiva y enlaces reales a WhatsApp e Instagram.

## Instalar

```bash
npm install
```

En Windows, si PowerShell bloquea `npm`, usar:

```bash
npm.cmd install
```

## Correr en desarrollo

```bash
npm run dev
```

O en Windows:

```bash
npm.cmd run dev
```

Después abrir `http://localhost:3000`.

## Editar datos

- Servicios, galería, WhatsApp e Instagram: `data/site.js`
- Secciones visuales: `components/`
- Estilos globales y paleta: `app/globals.css` y `tailwind.config.js`
